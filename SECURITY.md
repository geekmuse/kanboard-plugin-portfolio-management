# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | ✅ Yes    |
| < Latest | ❌ No    |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

To report a vulnerability, email: **brad@bradleyscampbell.net**

Include:
- Affected version
- Description of the vulnerability
- Steps to reproduce
- Potential impact

Expect acknowledgement within 72 hours and a resolution or status update
within 14 days.
